# Release checklist (owner-controlled; nothing is published without owner approval)

- [ ] Owner has frozen all confirmatory protocols (hash recorded in the registry)
- [ ] Every registered experiment has a truthful standalone report (11.3)
- [ ] Manuscript complete; PDF compiled and visually inspected
- [ ] Every number in the manuscript, reports, demo and articles maps to a result artifact (artifact_manifest.json)
- [ ] claims_audit.md completed; unsupported claims removed or qualified
- [ ] Clean clone: locked install, tests, smoke reproduction (reproducibility_report.md)
- [ ] Demo builds, works offline, keyboard accessible, fails closed on bad results
- [ ] Data manifest and licences verified; no non-redistributable data bundled
- [ ] Secret and personal-data scan clean
- [ ] Licence files unchanged; SPDX headers present
- [ ] author_review.md signed off by the owner
- [ ] Owner explicitly approves any push, release or publication
