# src

Python package `echo` (M2). Concerns are kept in separate modules: `config` (typed, validated configuration and hash), `vectors` (normalisation, cosine, angles), `catalogue` (synthetic catalogue and listeners), `policies`, `choice`, `preferences`, `simulate` (session loop), `metrics`, `schema` (result schema `echo.result.v1`), `manifest` (run manifest), `runner` (matrix expansion, freeze guard, serialization), `stats`, `report` (tables, figures, PDF), `smoke` (EXP-001 checks V1 to V6) and `cli`. Commands: see `CONTRIBUTING.md`.
